Privacy policy

Effective — 19 September 2026.

HK Career Agent is operated for its account owner. Gmail permissions support reading job alerts and recruitment replies, verifying the owner’s instructions, sending reports, and sending approved recruitment correspondence.

Necessary career facts, job details, application records, attachments, approval evidence, and operational metadata are held in private cloud storage. Production state and stored material snapshots are encrypted. OAuth credentials and model API keys are held in private secrets. Raw uploaded CV files are removed after parsing under the configured import policy; derived facts and necessary application materials remain for the workflow.

Job-alert links are extracted from Gmail locally. Alert excerpts and other information derived from Gmail remain Google user data. The production model pipeline sends independently retrieved public job descriptions and necessary de-identified career facts to Claude and DeepSeek for opportunity analysis and writing. Gmail-derived excerpts, complete emails, private correspondence, raw CVs, contact details, credentials, and tracking tokens are excluded from those model requests. De-identification does not guarantee anonymity; provider retention policies apply.

HK Career Agent’s use and transfer of Google user data comply with the Google API Services User Data Policy, including its Limited Use requirements.

The application does not sell user information, use it for advertising, or use Google user data to train generalized AI models. Gmail data is used only for the owner-requested functions described here. Employers receive application information only through the configured approval and submission process.

The owner can revoke Google access from their Google Account and stop the workflows. Revocation stops future access but does not delete existing records. Deletion requires removal of relevant stored records and retained cloud copies; it is not represented as instantaneous removal from provider backups or Git history.

For questions or deletion requests, use the support contact displayed on the application’s Google consent screen.
